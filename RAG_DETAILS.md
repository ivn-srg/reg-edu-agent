# RAG Agent - Детальная архитектура (продолжение)

## 4. Retrieval Phase - Semantic Gating

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    RETRIEVAL + SEMANTIC GATING                           │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  Query: "Что такое нормализация?"                                        │
│     │                                                                    │
│  ┌──▼────────────────────────────────────────────────────────────────┐   │
│  │ STEP 1: Query Embedding                                           │   │
│  │  model.encode(query) → [384 float]                                │   │
│  └──┬────────────────────────────────────────────────────────────────┘   │
│     │                                                                    │
│  ┌──▼────────────────────────────────────────────────────────────────┐   │
│  │ STEP 2: FAISS Search                                              │   │
│  │  ┌──────────┬─────────┬──────────┬───────────┐                    │   │
│  │  │Chat Type │ k       │ fetch_k  │ threshold │                    │   │
│  │  ├──────────┼─────────┼──────────┼───────────┤                    │   │
│  │  │question  │ 5       │ 10       │ 0.3       │                    │   │
│  │  │quiz      │ 6       │ 12       │ 0.4       │                    │   │
│  │  │task      │ 8       │ 16       │ 0.4       │                    │   │
│  │  └──────────┴─────────┴──────────┴───────────┘                    │   │
│  └──┬────────────────────────────────────────────────────────────────┘   │
│     │ fetch_k документов                                                 │
│  ┌──▼────────────────────────────────────────────────────────────────┐   │
│  │ STEP 3: Semantic Gating (validation.py)                           │   │
│  │                                                                   │   │
│  │  doc_embeddings = model.embed_documents(doc_texts)  # Батч        │   │
│  │  similarities = cosine_similarity([query_emb], doc_embeddings)[0] │   │
│  │  filtered = [doc for doc, sim in zip(docs, sims) if sim >= thr]   │   │
│  │                                                                   │   │
│  │  Пример (question, threshold=0.3):                                │   │
│  │  Doc1: 0.85 ✓  Doc6: 0.25 ✗                                       │   │
│  │  Doc2: 0.78 ✓  Doc7: 0.18 ✗                                       │   │
│  │  Doc3: 0.65 ✓  Doc8: 0.12 ✗                                       │   │
│  │  Doc4: 0.55 ✓  Doc9: 0.08 ✗                                       │   │
│  │  Doc5: 0.45 ✓  Doc10: 0.05 ✗                                      │   │
│  │                                                                   │   │
│  │  Результат: 5 документов                                          │   │
│  └──┬────────────────────────────────────────────────────────────────┘   │
│     │                                                                    │
│  ┌──▼────────────────────────────────────────────────────────────────┐   │
│  │ STEP 4: Context Formation                                         │   │
│  │  context = "\n---\n".join(doc.page_content for doc in filtered)   │   │
│  │  if not context: return "Информации нет в материалах"             │   │
│  └───────────────────────────────────────────────────────────────────┘   │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 5. Generation Phase

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         GENERATION PIPELINE                              │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │ STEP 1: History Management                                         │  │
│  │  • question: последние 4 сообщения                                 │  │
│  │  • quiz/task: последние 2 сообщения                                │  │
│  │  Конвертация: [SystemMessage, HumanMessage, AIMessage, ...]        │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ STEP 2: System Prompt (зависит от типа)                            │  │
│  │  ┌──────────────────────────────────────────────────────────────┐  │  │
│  │  │ QUESTION: Тьютор, диалоговый, направляющие вопросы           │  │  │
│  │  │ QUIZ: Тест-мейкер, строгий формат Markdown                   │  │  │
│  │  │ TASK: Задание-мейкер, структурированный формат               │  │  │
│  │  └──────────────────────────────────────────────────────────────┘  │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ STEP 3: Prompt Assembly                                            │  │
│  │  messages.append(HumanMessage(                                     │  │
│  │      f"Вопрос: {query}\nКонтекст:\n{context}\nОтвет:"              │  │
│  │  ))                                                                │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ STEP 4: LLM Invocation                                             │  │
│  │  ChatOllama(model="YandexGPT-5", temperature=0.2)                  │  │
│  │  response = llm.invoke(messages)                                   │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 6. Validation Phase (только question)

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    VALIDATION (validation.py)                            │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐  │
│  │ CHECK A: Term Overlap                                              │  │
│  │  1. Извлечь термины (regex, фильтр стоп-слов, len>=3)              │  │
│  │  2. answer_terms ∩ context_terms                                   │  │
│  │  3. overlap_ratio = |overlap| / |answer_terms|                     │  │
│  │  4. term_valid = overlap_ratio >= 0.2                              │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ CHECK B: Embedding Similarity                                      │  │
│  │  1. embeddings = model.embed_documents([answer, context])          │  │
│  │  2. similarity = cosine_similarity(answer_emb, context_emb)        │  │
│  │  3. emb_valid = similarity >= 0.3                                  │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ CHECK C: Rejection Detection                                       │  │
│  │  is_rejection = любая фраза отказа в ответе                        │  │
│  └──┬─────────────────────────────────────────────────────────────────┘  │
│     │                                                                    │
│  ┌──▼─────────────────────────────────────────────────────────────────┐  │
│  │ FINAL DECISION                                                     │  │
│  │  is_valid = (term_valid OR emb_valid) AND NOT is_rejection         │  │
│  │  if not is_valid: answer = "Информации нет в материалах"           │  │
│  └────────────────────────────────────────────────────────────────────┘  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 7. Сравнение 3 типов чатов

```
├────────────────┼──────────────┼──────────────┼──────────────┤

│ Prompt Style   │ Тьютор       │ Тест-мейкер  │ Задание      │

```

## 8. Оптимизации

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         OPTIMIZATIONS                                    │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  1. RAG Instance Caching: _rag_cache[k] → избегание перезагрузки         │
│  2. Embeddings Caching: _embeddings_cache → модель загружается 1 раз     │
│  3. Batch Processing: batch_size=32 для embeddings                       │
│  4. History Limiting: только последние N сообщений                       │
│  5. Fetch-k Strategy: k*2 предварительная выборка + фильтрация           │
│  6. Frozenset: O(1) lookup для стоп-слов                                 │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 9. Technology Stack

```
Backend:
  • FastAPI - API framework
  • SQLAlchemy - ORM
  • SQLite - Database
  • LangChain - RAG framework
  • FAISS - Vector store
  • SentenceTransformers - Embeddings (paraphrase-multilingual-MiniLM-L12-v2)
  • Ollama - LLM provider (YandexGPT-5-Lite-8B-instruct)
  • scikit-learn - Cosine similarity

Frontend:
  • React 19 + TypeScript
  • Zustand - State management
  • TailwindCSS - Styling
  • Vite - Build tool
```
